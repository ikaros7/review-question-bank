# 复习题库公开版

这是与完整认知模型工作台物理隔离的静态公开版，只包含复习问题、参考答案、机制链、成立条件、常见误区和设备本地字体偏好。

不包含案例记录、`current-record.json`、项目治理资料、用户决定或写入能力。字体设置保存在当前浏览器，不跨设备同步。

## 本地验证

```bash
npm install
npm run build
```

## GitHub Pages

将本目录作为独立公开仓库的根目录推送到 GitHub，随后在仓库 Settings → Pages 中选择 **GitHub Actions**。后续推送到 `main` 会自动更新页面。
